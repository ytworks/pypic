## Product

**Goal** (owner request 2026-11-09; roadmap `docs/roadmap.md`): a GPU-accelerated, multi-GPU,
3-D special-relativistic electromagnetic PIC engine for plasma experiments.

- Two schemes, switchable: explicit (relativistic Buneman–Boris, Esirkepov, Yee; Gauss and
  div B to round-off) and implicit (Crank–Nicolson + implicit midpoint; total energy and
  charge conserved exactly). Cubic (CIC) macro-particles.
- Boundaries per face: periodic, open, reflecting. Species: electron, ion (mass ratio, Z),
  positron; e-i / e-p / e-i-p mixtures, charge neutral by construction.
- Experiments are set up from physics (linear theory → box, grid, dt, run length); first
  example: 3-D two-stream instability.
- Hardware: 8× RTX PRO 6000 Blackwell (SM120), single node, NCCL; CPU-only CI on GitHub.

### 2026-11-12 — [amendment] PIC-D13 sort: the temporaries of the particle sort in a memory pool of their own
- What: `pypic.particles.sort_memory`: the sort allocates its temporaries from a pool that nothing else uses; a sort of more particles than any before returns that pool's blocks (and the default pool's free blocks) to the device first, a smaller one is served from the blocks of the largest. Regression test in `fp64` and `compact` (fails on bad2803: the held bytes grow at each sort of more particles than the one before; passes now). Two-stream benchmark (50,331,648 particles, 8 GPUs, three alternating runs): medians 3.233 ms/step against 3.254 (`mixed`) and 2.829 against 2.858 (`compact`), ranges overlap. Not measured yet: device memory at gate and production size. Not gated.
- Why: under the rule of PIC-D13 (release only after a species passes its own largest number) the bytes held by the pool grew at the argsort of the sort in the blast wave at gate size (entry below); the regression test reproduces it with a number that falls and rises again. Emptying the default pool after every sort stops it too but costs +7.8 % (`mixed`) and +8.3 % (`compact`) of the benchmark step: not adopted.
- Refs: PIC-D13 (Sort, amended 2026-11-12), PIC-D19; `docs/plans/2026-11-11-compact-storage.md` ("The sort keeps its temporaries in a pool of their own"); `tests/gpu/test_engine.py`; PR #43
